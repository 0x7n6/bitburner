# 12. Worker live retiming

Initial workers trusted action durations calculated by the controller earlier.

Official game semantics showed this could drift as hacking level changed.

Workers therefore evolved so each worker recalculates:

```text
current hack time
current grow time
current weaken time
```

immediately before invoking the action.

Then:

```text
additionalMsec
```

is calculated from live duration and desired finish time.

Telemetry now includes:

```text
baseTime
lateBy
scheduledFinish
finishedAt
jitter
actual value
```

This eliminated an important timing assumption.
